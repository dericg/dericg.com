# Deric Garza — Personal Site MVP

A deployable, dependency-free personal landing page.

## Deploy
Upload `index.html` to any static host (Netlify, Vercel, GitHub Pages, S3, traditional hosting, etc.). No build step is required.

## Content model
The page is intentionally evidence-first:
- professional identity + positioning
- three flagship systems with maturity status and visible proof
- one useful idea
- working principles
- current exploration
- personal operating system
- contact CTA

## Contact
The current CTA uses `https://www.instagram.com/deric_g/` as a real contact path. Replace it with a preferred email, LinkedIn, or other professional channel whenever desired.
